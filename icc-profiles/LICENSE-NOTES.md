# Bundled ICC Profiles — License Notes

The export-PDF job (`api/jobs/06`) converts RGB raster pages → CMYK PDF/X-1a
using an embedded ICC output profile. CMYK is the **default** export color mode.

## Hard rule

- **ONLY freely-redistributable originals** may be bundled here:
  ECI, Idealliance, CIE consortium public releases.
- **NEVER** Adobe-shipped profiles (restrictive licensing).
- **Legal review is REQUIRED before adding any binary** — this is a pre-ship gate
  (see ADR-033). Until vetted, the binary is intentionally ABSENT and the default
  CMYK path raises `IccProfileUnavailableError` at runtime; ops flips the default
  to `color_mode='rgb'` if vetting fails.

## Registry → file mapping

`src/services/icc_registry.py` `BUNDLED_PROFILES` is the source of truth.

| id | label | condition | expected file |
|----|-------|-----------|---------------|
| `fogra39` | ISO Coated v2 (ECI) — EU offset | FOGRA39 | `Coated_FOGRA39.icc` |

## How to bundle (after legal sign-off)

1. Download the **original ECI** profile (e.g. `eci.org` "ISO Coated v2"
   → `ECI_Offset_2009/Coated_FOGRA39.icc`). Do not re-export from Adobe apps.
2. Record source URL + license terms + reviewer + date below.
3. Drop the `.icc` file into this directory (or the `ICC_PROFILE_DIR` deploy mount).
4. Verify: `icc_registry.load_bundled_icc(get_profile("fogra39"))` returns bytes.
